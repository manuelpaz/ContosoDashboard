# Contract: Service Interfaces

Interfaces live next to their implementations in `ContosoDashboard/Services/` (existing
convention: interface + class in one file) and are registered as scoped services in
`Program.cs`. Signatures are the contract; bodies are defined during implementation.

All methods that touch user-visible data take `requestingUserId` and return `null`/`false`/an
empty result when access is denied (existing IDOR pattern). Denied and not-found are
indistinguishable to callers.

## IFileStorageService (`Services/FileStorageService.cs`)

Stakeholder-defined abstraction; `LocalFileStorageService` is the training implementation.

```csharp
public interface IFileStorageService
{
    // storageKey: relative key "{userId}/{projectId|personal}/{guid}.{ext}" generated by the caller.
    // Returns the key actually stored (same value for local storage).
    Task<string> UploadAsync(Stream fileStream, string storageKey, string contentType);
    Task DeleteAsync(string storageKey);               // no-op if missing
    Task<Stream> DownloadAsync(string storageKey);     // throws FileNotFoundException if missing
    Task<string> GetUrlAsync(string storageKey, TimeSpan expiration);
}
```

- `LocalFileStorageService`: root from `FileStorage:RootPath` (default `AppData/uploads`);
  rejects keys resolving outside the root; creates folders as needed. `GetUrlAsync` throws
  `NotSupportedException` — local files are only served through the authorized endpoints
  (reserved for a future Azure SAS implementation).

## IDocumentService (`Services/DocumentService.cs`)

```csharp
public interface IDocumentService
{
    // Upload (FR-001..FR-010, FR-028, FR-030)
    Task<DocumentUploadBatchResult> UploadDocumentsAsync(
        IReadOnlyList<DocumentUploadFile> files, DocumentUploadMetadata metadata,
        int requestingUserId, int? taskId = null);

    // Browsing and search (FR-018..FR-021, FR-027, FR-029, FR-031)
    Task<List<Document>> GetMyDocumentsAsync(int requestingUserId, DocumentQuery query);
    Task<List<Document>> GetSharedWithMeAsync(int requestingUserId);
    Task<List<Document>> GetProjectDocumentsAsync(int projectId, int requestingUserId);
    Task<List<Document>> GetTaskDocumentsAsync(int taskId, int requestingUserId);
    Task<List<Document>> GetAttachableDocumentsAsync(int taskId, int requestingUserId);
    Task<List<Document>> SearchDocumentsAsync(string searchText, int requestingUserId);
    Task<List<Document>> GetRecentDocumentsAsync(int requestingUserId, int count = 5);
    Task<int> GetDocumentCountAsync(int requestingUserId);

    // Single document (FR-011..FR-017)
    Task<DocumentDetails?> GetDocumentAsync(int documentId, int requestingUserId);
    Task<DocumentContent?> OpenDocumentAsync(int documentId, int requestingUserId, bool preview);

    // Management (FR-023..FR-026, FR-029)
    Task<bool> UpdateMetadataAsync(int documentId, DocumentMetadataUpdate update, int requestingUserId);
    Task<DocumentUploadResult> ReplaceFileAsync(int documentId, DocumentUploadFile file, int requestingUserId);
    Task<bool> DeleteDocumentAsync(int documentId, int requestingUserId);
    Task<DocumentShareResult> ShareDocumentAsync(int documentId, IReadOnlyList<int> userIds,
        IReadOnlyList<string> departments, int requestingUserId);
    Task<bool> AttachToTaskAsync(int documentId, int taskId, int requestingUserId);
}
```

### Supporting types (same file)

| Type | Members | Notes |
|------|---------|-------|
| `DocumentUploadFile` | `FileName`, `Size`, `Content` (Stream) | Browser content type is ignored (R5) |
| `DocumentUploadMetadata` | `Category`, `Description?`, `ProjectId?`, `Tags`, `Titles` (per file name) | Shared across the batch; titles default to file name without extension |
| `DocumentUploadResult` | `FileName`, `Succeeded`, `DocumentId?`, `ErrorMessage?` | Per file |
| `DocumentUploadBatchResult` | `Results` list, `SucceededCount` | One notification per batch |
| `DocumentQuery` | `SortBy` (Title/UploadedDate/Category/FileSize), `Descending`, `Category?`, `ProjectId?`, `FromDate?`, `ToDate?` | FR-019 |
| `DocumentMetadataUpdate` | `Title`, `Description?`, `Category`, `Tags` | FR-023 |
| `DocumentPermissions` | `CanEditMetadata`, `CanReplace`, `CanDelete`, `CanShare` | See permission matrix in [data-model.md](../data-model.md) |
| `DocumentDetails` | `Document`, `Permissions`, `CanPreview` | `CanPreview` = PDF or image |
| `DocumentContent` | `Content` (Stream), `FileName`, `ContentType` | Caller disposes the stream |
| `DocumentShareResult` | `Succeeded`, `RecipientsAdded`, `ErrorMessage?` | |

Behavioral guarantees:

- `UploadDocumentsAsync` validates each file independently (size → extension → scan), then
  generates key → saves file → saves record; deletes the file if the record save fails; logs
  `Upload`; sends one `DocumentAdded` notification per project member/manager (excluding the
  uploader) when ≥ 1 file succeeded and a project is set. With `taskId`, verifies task access,
  associates the task's project (overriding `metadata.ProjectId`) and creates `TaskDocument`.
- `OpenDocumentAsync` logs `Download` or `Preview`; returns `null` for preview of non-PDF/image.
- `DeleteDocumentAsync` logs `Delete` (with title/type snapshot) before removing the record,
  then removes the file.
- `ShareDocumentAsync` requires uploader; skips the uploader and existing recipients; notifies
  each new recipient once (department members expanded at share time for notifications only).

## IDocumentReportService (`Services/DocumentReportService.cs`)

```csharp
public interface IDocumentReportService
{
    // Returns null unless the requesting user is an Administrator (FR-033).
    Task<DocumentReport?> GetReportAsync(int periodDays, int requestingUserId);
}
```

`DocumentReport`: `UploadsByFileType` (type, count), `TopUploaders` (user, count, top 10),
`TopAccessedDocuments` (title, accesses, top 10), `DailyAccesses` (date, count).
